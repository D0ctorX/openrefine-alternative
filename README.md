# ⚡ Lightweight In-Browser OpenRefine Alternative — Tidify

👉 **[Try Tidify Live in Your Browser (Zero Install, 100% Client-Side)](https://tidify-app.netlify.app/?utm_source=github_openrefine)**

Need to clean a messy CSV or Excel (`.xlsx`, `.xls`) file without installing Java or setting up a local OpenRefine server?
**Tidify** runs 100% inside your browser's local memory:
1. **Strict Row Deduplication** (after trimming hidden Unicode/non-breaking whitespace).
2. **Automatic Date Standardization** (`YYYY-MM-DD` ISO or `DD/MM/YYYY` EU).
3. **Contact & Financial Normalization** (Proper Case names, lowercase emails, pure numeric salaries/amounts).
4. **Optional Semantic AI Clustering** for residual typos without sending personal rows.
